# FruitFly Roblox Agent — Stats + Potential + Reflex

**139,255** FlyWire-scale LIF units · Windows laptop.

## Fly Stats (permanent `fly_stats.json`)

| Stat | Role |
|------|------|
| LUCK | Better rare loot |
| FOOD | Inventory / heal spend |
| ITEMS | Gear count |
| POWER | Motor force |
| SPEED | Move / look |
| RAGE | Attack commit |
| SHIELD | Tank |
| VITALITY | Survive |
| FOCUS | Faster decide |
| GRIT | Mistake recovery |

Each has a **hard max**. At max the fly stops receiving that reward and says things like **"MAX & POWERFUL — STAT can't go higher."**

When **every** stat is maxed: **"ALL STATS MAX — you're fully powered."**

Kills, portals, loot drops, avoids auto-feed stats.

## Also included

- Potential XP unlocks (snap aim, overdrive…)
- Reflex reactions (water / portal / loom)
- Mistake + win memory
- Ultra-fast mouse/keys

## Run

```bash
git pull
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run_app.py
```

Windows only.
